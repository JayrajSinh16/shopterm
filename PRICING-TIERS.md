# Pricing Tiers

## Free

- Checkbox on cart page (theme block)
- Required / optional checkbox toggle
- Custom message text and T&C link
- Basic error message only no customization
- Block express checkout buttons (PayPal, Apple Pay, Shop Pay)
- Works with drawer/slide-out carts
- 50 consent logs stored (rolling)
- Basic position options (above / below checkout button)
- English language only

---

## Pro ($4.98/month)

Everything in Free, plus:

- **Unlimited consent log storage**
- **CSV export** of consent records
- **Analytics dashboard** — today / weekly / all-time stats + daily trend chart
- **Consent log search & filters** — filter by email, date range
- **Full appearance customization** — font size, font color, checkbox color, link color, underline toggle, max width, alignment
- **Multi-language theme editor UI** — settings labels translated for merchants in EN, DE, ES, FR (storefront text is set manually by the merchant)
- **Checkout extension** (Shopify Plus) — enforces T&C directly inside checkout
- **Cart attributes** written per consent for order-level audit trail
- **IP + user agent capture** in consent records
- **Checkbox version snapshot** — stores exact message text at time of consent
- **Priority support**

---

## Notes

- Consent logging (for compliance) is a Pro-only feature — free tier shows the checkbox but does not record logs
- Checkout extension requires Shopify Plus regardless of tier
- All stored data is per-shop and never shared
